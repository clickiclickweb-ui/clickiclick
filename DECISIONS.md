# Decisiones de diseno — Reorientacion inmobiliaria (Mayo 2026)

## Tipografia
- **Antes:** Syne (headings) + Inter (body). Syne es demasiado ancha/extendida para un publico de negocio.
- **Ahora:** Outfit (todo). Moderna, profesional, legible. Funciona bien en headings pesados (800) y body ligero (300-400). Siguiendo directrices de diseno profesional (taste-skill), ambas fuentes anteriores tenian problemas: Syne es excentrica para negocio, Inter es generica.

## Logo
- **Antes:** Imagen raster base64 (PNG ~15KB inline). Pesada, no escalable.
- **Ahora:** CSS text con Outfit 800. "CLICKI" en naranja + "CLICK" en navy/blanco. Carga instantanea, escalable, editable.

## Cursor personalizado
- **Eliminado.** Los cursores custom son un anti-patron de UX: reducen rendimiento, confunden en tactil, y no aportan a la conversion. Directriz profesional clara.

## Cromatica
- **Mantenida:** Navy #1a2744 + Orange #FF5500. La combinacion es fuerte y funciona para el nicho inmobiliario (confianza + energia). Un solo color acento, saturacion contenida.

## Estructura del hero
- **Antes:** Centrado con texto grande.
- **Ahora:** Split screen (texto izquierda, mockup derecha). Mas profesional, mejor uso del espacio, sigue directrices anti-center-bias para variance alta.

## Contenido reorientado
- Hero habla directamente a inmobiliarias boutique.
- Servicios reenmarcados para RE: "Web inmobiliaria completa", "SEO local inmobiliario", etc.
- Precios actualizados al rango correcto para servicios especializados.
