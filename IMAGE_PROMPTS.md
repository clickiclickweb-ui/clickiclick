# Prompts de imagen para propiedades ficticias

Pool compartido de imagenes para las 3 demos (Solara, NovaCasa, Fincas del Sur).
8 propiedades, ~5 imagenes por propiedad = ~40 imagenes totales.

## Herramienta sugerida
Midjourney v6 o DALL-E 3. Formato 16:9 para hero/galeria, 4:3 para thumbnails.
Estilo: fotografia inmobiliaria profesional, luz natural, staging home, sin personas.

## Notas para el cliente
- Los prompts estan listos para Midjourney o DALL-E 3
- Formato principal: 16:9 (para hero y galeria) con alguno en 4:3 (thumbnails)
- Estilo consistente: fotografia inmobiliaria profesional, sin personas, home staging
- Cada propiedad cubre: fachada + salon + cocina + dormitorio + un extra relevante
- Total: 8 propiedades x 5 imagenes = 40 imagenes
- Las imagenes se comparten entre las 3 demos (mismo pool de propiedades)
